# Changelog

## 2.0.0

Полная переработка графической версии и чистка репозитория.

### Новое
- Клетки рисуются и стираются мышью прямо на главном поле (без отдельного окна), с непрерывной линией при быстром движении мыши.
- Библиотека готовых фигур: глайдер, LWSS, мигалка, пульсар, пентадекатлон, ружьё Госпера, R-пентамино, «Желудь», Diehard.
- Кнопки «Step» и «Clear», горячие клавиши, всплывающие подсказки.
- Переключатель замкнутых краёв и опция «Stop on repeat»; в статусе указывается период найденного цикла.
- Поле масштабируется под размер окна; поддержка High-DPI; иконка приложения.
- Консольная версия: аргументы командной строки, ввод без падений, отрисовка без мерцания, корректное определение циклов.
- Unit-тесты движка и автоматическая сборка/релиз через GitHub Actions.

### Исправлено
- Мерцание при отрисовке (включена двойная буферизация).
- Ползунок скорости не влиял на скорость до первого перемещения (таймер стартовал с 100 мс).
- После повторной инициализации поля не сбрасывались счётчик поколений и история состояний —
  игра могла сразу остановиться с ложным сообщением о повторе.
- Популяция показывала 0 до первого шага.
- История состояний росла без ограничений.

### Удалено
- Скомпилированные файлы (`bin/`, `obj/`, `.exe`) из репозитория — exe теперь публикуется в Releases.
- Неиспользуемая форма `Form1` и шаблонные файлы ресурсов.
